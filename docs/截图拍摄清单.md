## 图 7：批处理 + SQLite 结果

**用途**：证明 Spark SQL 批处理（对应报告 5.7）

**命令**：
```powershell

.\.venv\Scripts\python.exe -c "import sqlite3;c=sqlite3.connect('news_pulse.db');[print(r[0],'->',r[1]) for r in c.execute('SELECT keyword,cnt FROM trends ORDER BY cnt DESC LIMIT 10')]"
```

**要拍到的内容**：

**关键点**：关键词是**实义词**（不是 `says` / `are` 这类虚词），体现停用词过滤生效
